First public release on GitHub. For everything before this release, see the commit history.

### New

- Realtime inbox: chat previews and unread counts now update live
- Conductors can edit passenger seat allocations
- Chat and inbox titles localized in Hindi and English, with an info sheet for chat rooms
- Web demo runs on OpenStreetMap tiles, no API key needed

### Fixed

- Passenger approval now refreshes UI and counts correctly
- Stale chat previews and unread counts; stream errors surface instead of hanging silently
- Session error on splash now shows a retry button
- Inbox tiles show ink splash feedback again

### Under the hood

- Android toolchain upgraded to Gradle 8.14.3, AGP 8.11.1, Kotlin 2.2.20
